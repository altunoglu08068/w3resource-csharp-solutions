# 012. Repeat Number in Rows

**Kaynak:** [w3resource - C# Basic Exercises #12](https://www.w3resource.com/csharp-exercises/basic/csharp-basic-exercise-12.php)  
**Konu:** Basic Exercises  

---

## 📝 Soru Açıklaması

Kullanıcıdan bir sayı/rakam girmesini isteyen ve bu sayıyı 4 satır boyunca aşağıdaki ardışık desende 2 kez tekrarlayarak ekrana yazdıran bir C# programı yazın:
- 1 satır aralarında boşluklu (`n n n n`)
- 1 satır bitişik (`nnnn`)
